## 输出要求

请输出严格的 JSON 数组, 每个元素表示一个关联:

```json
[
  {
    "chunk_id": "代码片段 ID",
    "relevance": 1-5,
    "link_type": "direct | indirect | reference",
    "reason": "为什么相关 (一句话)",
    "confidence": 0.0-1.0
  }
]
```

## 字段说明

- `relevance`: 1=完全无关, 2=弱相关, 3=可能相关, 4=很可能相关, 5=直接相关
- `link_type`:
  - `direct`: 直接实现该需求的功能
  - `indirect`: 间接影响 (被需求调用 / 调用需求)
  - `reference`: 仅作为参考 (类似功能 / 工具方法)
- `confidence`: 综合置信度
- 只输出 relevance >= 3 的项

## 评分原则

1. **优先 direct**: 真正实现需求功能的代码
2. **关注调用关系**: 上下游链路
3. **关注业务域**: 同业务域的代码更可能相关
4. **谨慎给高分**: 5 分必须是非常明确的直接关联

## 注意

只输出 JSON 数组, 不要有任何解释. 如果没有匹配的代码, 输出空数组 `[]`.
